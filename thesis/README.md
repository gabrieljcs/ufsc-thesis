# Dissertation source

This directory contains the LaTeX source, figures, bibliography, UFSC template files, and a compiled PDF for the dissertation. The main document is `main.tex`; run `make` from this directory to build it.

The source was copied from the local `ufscthesisx` checkout on 2026-10-19. The UFSC template and its images originate from the [ufscthesisx project](https://github.com/ufsc/ufscthesisx); the research text and generated figures are maintained here alongside the evaluation code.

The corrected response dataset is stored as `outputs/releases/2026-09-09-corrected/dataset_corrected.jsonl.gz` at the repository root. Decompress it to recover the original JSONL file (SHA-256 `ef79a4d610c5f0ea888102f7cd2658a0cf7a1d7004ee6eccb16987ae78e8b1c1`).
